## 搬瓦工限量版方案常见问题

### MINICHICKEN 是 CN2 线路吗？

不是。它走弗里蒙特机房的 HE（Hurricane Electric）直连线路，三网都是普通路由，没有国内优化。它是目前在售限量版里最便宜的一款，也是线路最普通的一款，买之前先想清楚用途。

### DC99 和 DC9 是同一个机房吗？

物理位置同址，但是两个不同节点。DC99 是搬瓦工后来启用的灰度测试节点，走三网 CN2 GIA 回程，性能表现和知名的 DC9 相差无几。Box 基础系列用的是 DC99，下单时别和 DC9 搞混。

### Box 系列买低了能升级吗？

可以。BIGGERBOX 买到手后能在 KiwiVM 后台补差价升级到 POWERBOX，整个系列从 512MB、1GB 到 1.5GB 内存形成一个完整的升级阶梯，不确定需求时先买低配再升级也是条路。

### 限量版一直没货，又想马上用 CN2 GIA 怎么办？

两条路：一是等 THE PLAN 2024 这类多机房限量版返场；二是直接上常规 CN2 GIA-E，$169.99/年起、也支持 $49.99/季付，12+ 个机房随时迁移，长期用更省心。
